04 / 方法與指標

怎麼讀這份分析

MSE / 均方誤差

預測誤差平方的平均；越低越好，大誤差會被放大。

RMSE / 均方根誤差

MSE 開平方，與獲利同單位；數值越低越好。

MAE / 平均絕對誤差

預測誤差絕對值的平均；越低越好，較少放大離群誤差。

R² / 決定係數

相對於平均值基準所解釋的變異；越接近 1 通常越好，也可能小於 0。

State / 地區編碼

California 作為基準類別；展開為 State_Florida 與 State_New York。

驗證方式

random_state=42 固定切分；編碼器只在訓練集 fit，避免測試資料洩漏。
